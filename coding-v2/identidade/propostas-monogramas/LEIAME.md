# Monogramas do Coding: CD, CL e CDL

Nove propostas de identidade em SVG vetorial (formas e caminhos reais, sem imagem embutida, sem fontes). Todas derivam da **Fluxo · Corte**: formas arredondadas, traço-base de espessura constante, azul da família Fluxo e o toque em azul-gelo (`#8fe9ff`).

**Status:** exploração. Nada aqui é usado pelo app, pelo Launcher ou pelo site. A identidade atual (`public/legacy-icons/coding.svg`) continua valendo. Esta pasta fica fora de `public/` e do build.

| Grupo | Uso | Proposta | Ideia |
|---|---|---|---|
| CD | Coding | `cd-nucleo` | D sólido em gelo dentro do anel C |
| CD | Coding | `cd-trama` | C e D entrelaçados, com vão fino entre eles |
| CD | Coding | `cd-negativo` | D branco com C vazado e canto cortado em gelo |
| CL | Coding Launcher | `cl-cauda` | C que endireita e vira L, com pé em gelo |
| CL | Coding Launcher | `cl-passagem` | L em gelo atravessa a abertura do C |
| CL | Coding Launcher | `cl-fluxo` | C da Fluxo com base reta e pé de L separado pela fenda |
| CDL | Coding Launcher | `cdl-raiz` | anel C que desce até o pé do L, com D no centro |
| CDL | Coding Launcher | `cdl-camadas` | anel C, D em gelo e L vazado dentro do D |
| CDL | Coding Launcher | `cdl-corte` | C da Fluxo com D em gelo no miolo e pé de L |

## Arquivos de cada proposta
`simbolo.svg` (só o glifo), `icone.svg`, `icone-claro.svg`, `icone-escuro.svg`, `favicon.svg` (versão simplificada para 16/32 px), `logo-horizontal-claro.svg`, `logo-horizontal-escuro.svg` (com o nome completo: "coding" nas propostas CD; "coding" + "launcher" nas CL e CDL) e `abertura.svg` (tela de abertura). O texto "Abrindo o Launcher..." de `abertura.svg` é a única fonte do sistema, e é ilustração.

## Decisão
Ainda não há escolha. O dono decide: qual CD fica com o Coding, e se o Launcher usa CL ou CDL (e qual proposta). Só depois disso a identidade entra numa versão do app, com registro em `versions-data.ts` e testes.
